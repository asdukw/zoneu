# v2.2.0 —— 界面重做与角色卡头像

`v2.1.0` 以来的界面重做与角色卡修复，无破坏性变更，可直接覆盖安装。

## 新增

- **界面重做**：全局采用 Material 3 Expressive 的排版与组件——大标题、分组卡片、胶囊按钮；移除底部导航栏，聊天、设置、酒馆、角色与世界书走单一推进路径。
- **角色详情页重做**：卡图、名字、标签一眼可见；「开始对话」是唯一主操作，收藏与编辑并列；人设、性格、开场等长正文默认显示五行，可展开全文；导出与导入收进「分享与备份」的设置行。
- **列表显示卡图**：角色库与酒馆侧栏显示角色卡头像，没有图片时使用中性占位。
- **酒馆一个入口**：侧栏酒馆页集中角色卡会话、群聊入口，以及本段会话的世界配置与模型。

## 改进

- 默认界面不再暴露技术细节：聊天顶栏去掉 token 计数与运行摘要，工具过程与导入兼容信息按需展开。
- 删除、保存等一句话结果改为底部短提示，不再在页面里留一张不会消失的卡片。
- 「另开支线」只在后面确实还有消息时出现。

## 修复

- 提问的回答作为一条独立的用户消息出现在对话里，不再连同它前面的助手输出一起被吞掉。
- 角色卡头像：从 PNG 直链导入的卡保留图片；Chub 的 WebP 头像可以下载并显示；旧卡可在重新导入时补回。
- 「正在启动 dsh 运行时…」不再被固化进消息正文。

## 验证

- 本地 `spotlessCheck`、`detekt`、`:app:lintDebug`、`:app:testDebugUnitTest`、`:app:compileDebugAndroidTestKotlin` 全过。
- 真机验证：角色详情页折叠 / 展开、角色库与侧栏头像、删除后的底部提示、`ask_user_question` 回答落位。
