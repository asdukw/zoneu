# v2.1.0 —— 头像导入、设置文案与会话恢复

`v2.0.0` 以来的功能与体验改进，无破坏性变更，可直接覆盖安装。

## 新增

- **网络角色卡头像**：从受支持的 Chub / CharacterHub 公开页面导入角色卡时，如果 metadata 明确提供 HTTPS 头像地址，会下载一张 PNG 头像保存到应用私有目录。重新导入只补缺失的头像，不覆盖已有文件。边界见 `docs/roleplay.md`。
- **本地 PNG 角色卡资产**：导入 PNG 角色卡时，头像图片与卡数据一起保存；此前重复导入导致缺失头像的卡会在再次导入时补回。
- **提供商图标**：模型服务页显示 Anthropic、DeepSeek、OpenAI、OpenCode、OpenRouter 的图标；刷新前情提要的入口同步更新。
- **会话恢复**：应用或内嵌运行时重启后，同一会话会接回已持久化的 dsh 会话记录；中断的轮次被关闭，上个进程残留的排队输入被清空。卡住的轮次可以显式取消，不必新开会话。
- **侧栏返回**：聊天侧栏打开时，系统返回键 / 侧滑关闭侧栏，不再退出整个应用。

## 改进

- 设置界面文案改为面向用户的任务导向语言，移除实现术语；写入类操作明确说明需要确认。
- Gmail 能力描述与当前读写能力一致，并说明写操作需要确认。
- 酒馆预设编辑器改为内部默认配置，不再对用户暴露；磁盘上的旧预设文件保留不动。

## 修复

- 修复 Android 运行时补丁重复装配时无法识别已应用状态的问题：会话恢复的 dispatch 分支插入位置拆散了 world-lifecycle 补丁的连续锚点，导致第二次装配失败。
- 修复 OpenAI 服务图标。

## 验证

- CI（静态检查、JVM 单测、离线自检）全绿。
- 本地通过 `spotlessCheck`、`detekt`、`:app:lintDebug`、`:app:testDebugUnitTest`、`tools/offline-checks.sh` 和 `bundle-dsh.ps1` 装配。
- 本版发布前没有可用的真机，未进行真机冒烟；执行层与内嵌 Node 的真实任务验证留待安装后确认。
