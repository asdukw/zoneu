# v2.3.0 —— 补丁更新与世界书修复

`v2.2.0` 以来的更新链路改进与修复，无破坏性变更，可直接覆盖安装。

## 改进

- **应用内更新补丁优先**：只下载变化的部分（覆盖最近几个版本），补丁不可用、校验不过或空间不足时自动改下完整包，行为与以前一致。同一次更新在运行时归档字节稳定后从 156 MiB 降到约 4 MiB。
- **首页示例**换成「帮我整理一下近期的邮件」，不再拿查看电量这类纯设置操作当例子。

## 修复

- 世界书复制：名字已到 512 字上限时仍保留「· 副本」后缀。
- 删除角色卡后的默认绑定清理不再要求 UUID —— 能绑定过的卡片 id 都能清理。

## 验证

- 发布 workflow 在签名出包前跑 `spotlessCheck`、`detekt`、`:app:lintDebug`、`:app:testDebugUnitTest`。
- 本机：`assembleRelease` 出包并装到日常机上，升级后数据库与密钥保留。
